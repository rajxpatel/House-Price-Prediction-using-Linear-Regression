# House-Price-Prediction-using-Linear-Regression
This project predicts house prices using Multiple Linear Regression.  The aim is to understand how various housing characteristics influence house prices and to build a predictive model using statistical and machine learning techniques.
# Dataset

The dataset contains 545 residential houses with the following attributes:

Area
Bedrooms
Bathrooms
Stories
Main Road
Guest Room
Basement
Hot Water Heating
Air Conditioning
Parking
Preferred Area
Furnishing Status
House Price (Target Variable)
